# 공개 범위와 한계

## 포함·제외

콘텐츠 계약, 불변 bundle, 다운로드 재개·검증, 재접속 복구, 최신 목표 처리, Qt 파일 이벤트·파싱·재생 경계를 포함합니다.

실제 관리 웹·계정 DB·배포 설정, 소프트웨어 OTA, 전원 관리, 원격 서비스 명령, 현장 영상·자막·일정·로고·폰트, 주소·기기 alias·인증·로그·Git 전체 이력은 제외했습니다.

## 기능적 한계

- playlist source는 준비된 로컬 영상입니다. 외부 실시간 스트림과 YouTube Live는 계약 범위 밖입니다.
- 일정 시간대는 Asia/Seoul이며 층별 모델에도 제약이 있습니다. 범용 국제화 일정 플랫폼은 아닙니다.
- Qt 앱은 Linux 물리 DRM 화면 선택을 사용합니다. Mac 코어 테스트로 Pi HDMI·Wayland·디코딩을 보장하지 않습니다.
- 전체 다운로드·검증 후 적용하므로 전송 시간을 제거하지 않습니다.
- hash는 무결성 검사입니다. 예제 서버는 운영 인증·권한·보안 배포 구성을 제공하지 않습니다.
- 합성 테스트를 실기기 가동률·무중단·대규모 운영 성과로 표현하지 않습니다.

## 기간

사용자가 확인한 주요 개발 기간은 **2025.12–2026.03**, 공개 코드 snapshot은 **2026-10-10**입니다. 현재 운영 여부나 이후 유지보수 기간을 이 저장소에서 별도로 확정하지 않습니다.
